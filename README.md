# SGQ.js

JavaScript port of **Shifted-Grid Quantization (SGQ)** for browser-side
4-bit weight unpacking.

- Language: JavaScript
- License: Apache-2.0
- Status: active
- Implements: Shifted-Grid Quantization (SGQ)
- Benchmark (WQ-4 4-bit accuracy retention): 90.8

## Notes

Runs in WebGPU and WASM builds. Benchmark numbers were collected with
the WG-4 harness rather than the Python WQ-4 harness.
